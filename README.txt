CAT 일정 위젯 설치 방법

1. https://github.com/tmdrbs1591/Cat-Scheduler-Weiget/archive/refs/heads/main.zip 을 받아 압축을 풉니다.
2. install.bat 을 더블클릭합니다.
3. 바탕화면 오른쪽 위에 위젯이 뜨면 [Google 로그인]을 눌러 스케줄러 계정으로 로그인합니다.
4. 끝. 다음부터는 컴퓨터를 켜면 자동으로 실행되고 로그인도 유지됩니다.

업데이트
- 자동입니다. 위젯이 켜질 때와 켜져 있는 동안 3시간마다 새 버전을 확인해서 알아서 업데이트합니다. (로그인 유지)
- 바로 확인하려면 트레이 아이콘 우클릭 > 업데이트 확인

- 위젯은 바탕화면에 붙어 있어서 다른 창을 쓰면 그 뒤로 숨습니다 (꺼진 게 아닙니다).
  작업표시줄 오른쪽 트레이의 파란 C 아이콘을 누르거나 Win+D 를 누르면 보입니다.
  트레이 아이콘 우클릭: 위젯 보이기 / 새로고침 / 사이트 열기 / 문제 보고 / 업데이트 확인 / 종료
- 위젯을 닫았다면 바탕화면의 'CAT Schedule Widget' 아이콘으로 다시 켤 수 있습니다.
- 지우려면 uninstall.bat 을 실행합니다.
- 문제가 생기면 report.bat 을 실행하세요. (또는 트레이 아이콘 우클릭 > 문제 보고)
  바탕화면에 "CAT위젯_문제보고.txt" 가 만들어지고 내용이 클립보드에 복사됩니다. 그대로 붙여넣어 보내주세요.
  (로그인 정보는 들어가지 않습니다)
- 설치 위치: %LOCALAPPDATA%\CatScheduleWidget

사용법
- 맨 위 검은 바를 잡고 끌어서 위치 이동, 가장자리를 끌어서 크기 조절
- 이름 클릭: 그 사람 일정 추가/빼기 · 더블클릭: 그 사람만
- 빈 칸 클릭/드래그: 일정 추가 (팝업이 떠 있는 동안 막대를 끌어 기간 조절)
- 막대 드래그: 날짜 이동 · 양 끝: 기간 조절 · 위아래: 줄/담당자 변경
- 클릭: 선택 후 Delete 삭제 · 더블클릭: 수정 · Ctrl+Z / Ctrl+Y
- 마우스 휠: 앞뒤 날짜 · [목록]: 아래 목록 숨기기

새 버전 배포하는 법 (관리자)
- app 폴더의 파일을 고치고 app/version.txt 의 숫자를 올려서(예: 2026.11.12.1 -> 2026.11.12.2) main 에 push 하면
  모든 사람의 위젯이 3시간 안에(또는 다음 실행 때) 자동으로 업데이트됩니다.
